# Controlled Generative UI — LearnIT

این نسخه از LangGraph، AI SDK UI و CopilotKit استفاده می‌کند. پایه همان هسته TypeScript موجود است؛ مثال‌های Python/FastAPI مستندات CopilotKit به این هسته تطبیق داده شده‌اند و یک ایجنت موازی یا چت‌بات مستقل جای آن را نگرفته است.

## نقش‌ها

- **LangGraph**: تحلیل، RAG، حل، بررسی، انتخاب scene در plan_visual، کنترل آن در validate_visual، آموزش و بازخورد. در حالت OpenAI، انتخاب نمایش یک فراخوانی ساختاریافته اضافه دارد و در سقف ۱۰ فراخوانی موفق هر سؤال قرار می‌گیرد.
- **AI SDK UI**: useChat و DefaultChatTransport در رابط؛ createUIMessageStream در API. پیشرفت واقعی Nodeها و نتیجه از SSE منتقل می‌شوند. پیام دارای data-progress، data-result و tool part با نام display_math است. متن توکن‌به‌توکن نمایش داده نمی‌شود؛ آموزش پس از بررسی پاسخ ارائه می‌شود.
- **CopilotKit**: runtime خودمیزبان در /api/copilotkit، کاتالوگ محدود از طریق useRenderTool و renderer از طریق useRenderToolCall. هیچ کد JSX/HTML/JavaScript از مدل اجرا نمی‌شود. renderer پیش از نمایش نوع و بازه داده را دوباره کنترل می‌کند.
- **Mafs**: محاسبه و نمایش نمودارها/شکل‌ها در React. تغییر پارامتر، بازنشانی و باز/بسته کردن نمایش به مدل درخواست نمی‌فرستند.

## یک هسته، دو transport

رابط اصلی با AI SDK UI درخواست را به /api/tutor می‌دهد. CopilotKit خروجی display_math را با renderer ثبت‌شده نشان می‌دهد. runtime نیز همان سرویس را با LearnITAgent به AG-UI عرضه می‌کند؛ این مسیر برای سازگاری agent clientهاست و با نمایش هر پاسخ دوباره Graph را اجرا نمی‌کند.

در /api/copilotkit/info عامل default قابل کشف است. run استاندارد AG-UI می‌تواند در forwardedProps.request یک درخواست معتبر start/resume داشته باشد؛ در غیر این صورت متن آخرین پیام user به start تبدیل می‌شود. فقط RequestBody شناخته‌شده پذیرفته می‌شود و state ارسالی مرورگر اجازه جایگزین کردن state مسئله در سرور را ندارد. قفل، TTL و مالکیت نشست از سرویس مشترک استفاده می‌کنند. برای جلوگیری از اشتراک replay بین cookieهای ناشناس، SessionRunner در runtime تاریخچه جداگانه جهانی ایجاد نمی‌کند. قابلیت replay، توقف runtime و ذخیره پایدار هنوز اضافه نشده‌اند.

## کاتالوگ مجاز v1

| kind | نمایش | دامنه فعلی |
| --- | --- | --- |
| function | نمودار و تغییر عمودی/بزرگ‌نمایی | چندجمله‌ای با حداکثر ۵ ضریب |
| tangent | نقطه و مماس | مشتق محاسبه‌شده از ضرایب |
| integral | انتگرال معین و ریمان | چندجمله‌ای، دو کران محدود |
| triangle | فیثاغورس و تغییر دو ضلع | فقط مثلث قائم |
| vector | جمع دو بردار | دو بردار دوبعدی |
| matrix | تبدیل خطی | ماتریس ۲×۲ و بردار کاوش اولیه (1,1) |

خروجی نسخه قرارداد uiSchemaVersion=1 دارد. scene علاوه بر پارامترهای نوع مربوط، title، caption و basis دارد. basis=example با برچسب مثال آموزشی نشان داده می‌شود تا داده تازه به مسئله اصلی نسبت داده نشود. UI اثبات صحت آموزش مدل نیست؛ verification پاسخ مستقل از اعتبار ساختار scene باقی می‌ماند.

## کنترل داده

نام ناشناخته، prop اضافی، مقدار نامتناهی، دامنه وارونه و پارامتر بیرون دامنه رد می‌شوند. مدل نمی‌تواند ضرایب یا بردار نتیجه ابزار معتبر را عوض کند. برای مسئله فاقد ابزار محلی، داده نمودار و پارامترهای صریح با متن سؤال نیز بررسی می‌شوند؛ این تطبیق محافظه‌کارانه است و parser عمومی همه فرمول‌ها نیست. داده مبهم باید به مثال دارای برچسب یا توضیح متنی برود.

اگر انتخاب UI شکست بخورد، آموزش معتبر حفظ می‌شود؛ نمایش معتبر ابزار در صورت وجود جایگزین می‌شود. هیچ iframe، URL، سبک آزاد یا action اجرایی مدل در این کاتالوگ وجود ندارد. محاسبات نمایش مانند شیب، انتگرال چندجمله‌ای، وتر و تبدیل بردار مستقیماً از داده عددی انجام می‌شوند.

## بررسی

گزارش اجرای این نسخه: ۵۳ تست منطق در هفت فایل، هفت تست مرورگر Chrome و TypeScript پاس شدند. انتخاب واقعی scene با Luna/AvalAI نیز برای مشتق و مثلث قائم آزمایش شد؛ درخواست اول نمودار function و درخواست دوم triangle انتخاب کرد. پاسخ مسئله هندسه همچنان وضعیت «تأیید مستقل نشده» دارد؛ محاسبه شکل به معنی تأیید تمام توضیح مدل نیست. endpoint کشف عامل CopilotKit و همراه بودن فایل RAG در خروجی هر دو API نیز بررسی شدند.

تست‌های منطق شامل کاتالوگ، دستکاری ضرایب، پارامتر خارج از محدوده، محاسبه دقیق مشتق/انتگرال، جریان واقعی Graph، مالکیت نشست و خروجی AG-UI هستند. تست مرورگر شامل جریان SSE واقعی، نمایش CopilotKit، کنترل بدون درخواست مدل، بازنشانی، پایان درس، عکس، MathLive و موبایل است. نمایش هندسه/انتگرال/ماتریس در تست مرورگر با scene کنترل‌شده شبیه‌سازی می‌شود؛ انتخاب آن‌ها توسط Luna باید جداگانه با درخواست واقعی بررسی شود.

## اجرا و نسخه‌ها

Node.js 24 برای محیط پروکسی توصیه می‌شود. `npm ci` سپس کپی `.env.example` به `.env.local` و `npm run dev:proxy`. React 19 حفظ شده است؛ `.npmrc` برای سازگاری محدودیت peer dependencyهای بسته‌های ترکیبی، legacy-peer-deps را فعال می‌کند. lockfile باید همراه پروژه باشد. فایل کلید وارد Git نمی‌شود و هیچ کلید CopilotKit Intelligence برای این مسیر self-hosted لازم نیست. Inspector محصول خاموش است.

# بازیابی پاسخ مشتقِ قابل محاسبه

برای درخواست صریح مشتق و مماسِ تابع `f(x)=...` تا درجهٔ دو، ضریب‌ها از نوشتار متنی یا توان سادهٔ LaTeX استخراج می‌شوند و مشتق با ابزار مستقل محاسبه می‌شود. اگر بازبین مدل پس از یک اصلاح هنوز پیش‌نویس را رد کند، Node `recover_verified_derivative` آن پیش‌نویس را کنار می‌گذارد و توضیح تازه‌ای از محاسبهٔ مستقیم مشتق، مقدار تابع، شیب و معادلهٔ مماس می‌سازد. سپس همان مسیر اعتبارسنجی و نمایش تعاملی اجرا می‌شود. این مسیر برای مشتق دوم، عبارت پشتیبانی‌نشده یا درخواست ترکیبی انتگرال فعال نمی‌شود. تست رد اجباری مدل و تست مرورگر برای سؤال تصویر پاس شدند.
