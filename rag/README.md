# منابع و تنظیمات RAG LearnIT

ایندکس همراه برنامه از ۳۶ بخش کتاب‌های OpenStax ساخته شده است؛ ۵۱۸ قطعه، هر قطعه حداکثر ۱۲۰۰ کاراکتر و overlap برابر ۱۸۰ کاراکتر. این محتوا بانک سؤال آماده اپ نیست. بازیابی فقط پس از ارسال سؤال کاربر در Node retrieve_context اجرا می‌شود.

## منشأ و مجوز

منبع: OpenStax، Rice University. کتاب‌ها: College Algebra 2e، Precalculus 2e، Calculus Volume 1، Calculus Volume 2، Calculus Volume 3، Contemporary Mathematics و Introductory Statistics 2e. لینک هر بخش، واژه‌های فارسی/انگلیسی و شناسه در sources.json ثبت شده‌اند. ایندکس‌ساز وجود لینک CC BY-NC-SA 4.0 را در هر صفحه کنترل کرده است.

محتوای متنی منابع و اقتباس‌های آن تحت [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) هستند. این مجوز برای استفاده غیرتجاری، با انتساب و اشتراک اقتباس تحت همان مجوز است. این توضیح مجوز کد برنامه نیست. UI نام OpenStax/Rice University، لینک اصلی، مجوز و تغییر قطعه‌بندی را کنار منابع هر پاسخ نمایش می‌دهد. [مقدمه و ضوابط رسمی](https://openstax.org/books/calculus-volume-1/pages/preface).

تغییرها: حذف ناوبری و اسکریپت‌ها، تصاویر و container تمرین/مثال؛ تبدیل presentation MathML به LaTeX بدون annotation تکراری؛ نرمال‌کردن فاصله‌ها و قطعه‌بندی. مقدمه‌های روایی کتاب ممکن است شامل مثال باشند؛ این‌ها محتوای کتاب‌اند و به‌عنوان سؤال شروع یا درس آماده در UI نمایش داده نمی‌شوند.

منابع حوزه‌ها در یک ایندکس مشترک قرار دارند و با کلیدواژه تخصصی و گسترش فارسی/انگلیسی بازیابی می‌شوند. این یک RAG واژگانی فعال است؛ صرفاً فهرست لینک نیست. پوشش جبر خطی و آمار مقدماتی است؛ مباحثی مانند مقدار ویژه، اثبات پیشرفته و تمام شاخه‌های دانشگاهی در ایندکس حاضر پوشش کامل ندارند.

BM25 محلی با k1=1.2 و b=0.75؛ واژه‌های فارسی سؤال با واژه‌های تخصصی انگلیسی گسترش می‌یابند. برای هر سؤال حداکثر سه قطعه و برای هر بخش حداکثر دو قطعه برمی‌گردد. متن زمینه حداکثر ۳۶۰۰ کاراکتر است؛ metadata کمی به این اندازه اضافه می‌کند. retrieval صرفاً واژگانی است؛ embedding یا vector database پیاده‌سازی نشده و هزینه embedding ندارد. در پاسخ OpenAI، افزودن context مصرف توکن ورودی دارد و در usage مدل ثبت می‌شود.

یک Promise بارگذاری، ایندکس را در حافظه فرآیند نگه می‌دارد؛ فایل index.json روی دیسک پایدار است. جست‌وجو در زمان درخواست روی این ایندکس انجام می‌شود، نه روی تمام اینترنت. منبع نامرتبط، نبود نتیجه یا نبود فایل به‌صورت وضعیت صریح مدیریت می‌شود. لینک‌ها فقط از HTTPS و دامنه allowlist شده openstax.org پذیرفته می‌شوند. منابع داده مرجع‌اند و به مدل دستور اجرای کد یا تغییر Graph نمی‌دهند.

## بازسازی

```powershell
cd 'E:/Codex File/Course/01/math-tutor'
npm run rag:index
```

این فرمان ۳۶ صفحه allowlist را دریافت می‌کند؛ به کلید مدل نیاز ندارد. بازسازی با سه دریافت هم‌زمان و timeout سی‌ثانیه‌ای هر صفحه انجام می‌شود. پس از موفقیت همه بخش‌ها، index.json و report.json نوشته می‌شوند؛ فایل index.json قبلی تا پایان دریافت‌ها نگه داشته می‌شود. report.json عنوان، URL، طول متن، تعداد قطعه و SHA-256 متن استخراج‌شده را ثبت می‌کند. پس از بازسازی، پردازش سرور را restart کنید تا cache فرآیند عوض شود.

## مرز قابلیت

در محیط دارای HTTP_PROXY/HTTPS_PROXY و Node.js 24، برای بازسازی از `npm run rag:index:proxy` و برای اجرای اپ از `npm run dev:proxy` استفاده کنید. همین تنظیم هنگام بازسازی واقعی این نسخه لازم بود. پس از تغییر ایندکس یا env، سرور را دوباره اجرا کنید.

این ۳۶ بخش تمام ریاضیات را پوشش نمی‌دهند. منبع مرتبط، اثبات درستی پاسخ یا حل‌گر نمادین نیست. در حالت محلی، محاسبه برای دامنه محدود ابزار انجام می‌شود و برای مفهوم فقط منابع مرتبط و نیاز به اتصال مدل اعلام می‌شود. توضیح فارسی آزاد، حل مسائل فراتر از ابزار محلی و بازآموزی تطبیقی به OpenAI تنظیم‌شده نیاز دارند. داده برداری نمودار به متن RAG یا prompt مدل اضافه نمی‌شود.
