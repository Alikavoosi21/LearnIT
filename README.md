# LearnIT — Complex Mathematics Tutor

Next.js + shadcn/ui، هسته واقعی LangGraph و CLI مشترک. جهت مصوب: گفت‌وگوی تیره، کهربایی و لوگوی C. رابط وب و CLI از یک هسته مشترک استفاده می‌کنند.

## اجرا

Node.js ۲۲ یا بالاتر برای فرمان‌های env-file و Python ۳٫۱۰ یا بالاتر برای CLI پایتون:

```powershell
cd LearnIT
npm ci
npm run dev
```

آدرس: http://localhost:3100. برای تولید: `npm run build` سپس `npm start`.

صفحه شروع خالی است؛ هیچ سؤال از پیش تعیین‌شده، نمونه درس یا تمرین ثابت در اپ نیست و هیچ Agentای پیش از ارسال سؤال کاربر اجرا نمی‌شود. حالت پیش‌فرض محلی و بدون کلید است. ابزار محلی فقط جمع تک‌جمله‌های ثابت، x و x²، معادله خطی یا درجه دوم و جمع دو بردار دوبعدی را پشتیبانی می‌کند؛ تابع‌های مثلثاتی، کسرها، نامعادله‌ها و پرانتزهای جبری در این ابزار نیستند. برای مفهوم، حالت محلی منابع مرتبط را بازیابی می‌کند و نیاز به مدل برای تولید توضیح فارسی را روشن اعلام می‌کند.

## اتصال OpenAI

`.env.example` را به `.env.local` کپی کنید و این مقدارها را تنظیم کنید:

```dotenv
TUTOR_MODE=openai
OPENAI_API_KEY=your-key
AI_BASE_URL=https://api.avalai.ir/v1
OPENAI_MODEL=gpt-6-luna
```

مدل انتخابی باید در حساب شما موجود باشد و Responses Structured Outputs را پشتیبانی کند. نام مدل عمداً اجباری و قابل تنظیم است. بعد از تغییر متغیرها سرور را دوباره اجرا کنید. کلید را در مرورگر یا متغیر NEXT_PUBLIC نگذارید. برنامه از Responses API با خروجی Zod، timeout سی‌ثانیه‌ای، یک retry شبکه و `store:false` استفاده می‌کند. تنظیم store:false جایگزین سیاست‌های نگه‌داری داده ارائه‌دهنده نیست.

فایل `.env.example` را به `.env.local` کپی کنید؛ `TUTOR_MODE=openai` و مدل `gpt-6-luna` آماده‌اند و فقط مقدار `OPENAI_API_KEY` را وارد کنید. این فایل در Git نادیده گرفته می‌شود. [مستندات رسمی Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) پشتیبانی ورودی تصویر و Structured Outputs را اعلام می‌کند. اگر از پروکسی HTTP_PROXY/HTTPS_PROXY استفاده می‌کنید، با Node.js 24 و فرمان `npm run dev:proxy` سرور را اجرا کنید تا درخواست مدل از پروکسی عبور کند.

مدل، تحلیل درخواست، نوشتن آموزش و بازبینی سازگاری را انجام می‌دهد. حل‌گر مستقل برای دامنه محلی به کار می‌رود؛ خارج از این دامنه، پاسخ با وضعیت «تأیید مستقل نشده» ارائه می‌شود. بازبینی مدل اثبات رسمی نیست. بازبینی ناموفق یک بار اصلاح می‌شود و در صورت شکست دوباره، جواب غلط آموزش داده نمی‌شود. اتصال زنده OpenAI هنوز با کلید واقعی آزموده نشده است؛ مسیر آداپتور با مدل ساختگی آزموده شده است.

## عکس و صفحه‌کلید ریاضی

دکمه گیره، عکس ثابت PNG، JPEG یا WebP را با حداکثر حجم ۳ مگابایت انتخاب می‌کند. چسباندن عکس از کلیپ‌بورد هم پشتیبانی می‌شود. پیش‌نمایش و حذف قبل از ارسال وجود دارد و ارسال عکس بدون متن مجاز است. نوع واقعی فایل، حجم و سقف ۱۶ میلیون پیکسل در سرور نیز بررسی می‌شود. فایل روی دیسک یا سرویس ذخیره‌سازی آپلود نمی‌شود؛ پیش‌نمایش در حافظه مرورگر است.

برای خواندن عکس، `TUTOR_MODE=openai` و مدل انتخابی دارای قابلیت بینایی و Structured Outputs لازم است. Node جدید `read_image` صورت مسئله را با یک فراخوانی مدل استخراج می‌کند؛ عکس ناخوانا به مسیر رفع ابهام می‌رود. عکس پس از استخراج از State حذف می‌شود و به مراحل حل، RAG یا بازآموزی دوباره ارسال نمی‌شود. توکن خواندن عکس در شمارنده همین سؤال ثبت می‌شود. متن و عکس ارسالی تابع سیاست‌های OpenAI هستند. فراخوانی واقعی بینایی بدون کلید معتبر آزموده نشده است.

[MathLive](https://mathlive.io/mathlive/guides/react/) با مجوز MIT، ویرایشگر فرمول و صفحه‌کلید مجازی را فراهم می‌کند. نمادهای پیشرفته شامل کسر، رادیکال، مشتق، انتگرال، حد، مجموع و ماتریس هستند. پنل از دکمه Σ باز می‌شود و فرمول پس از تکمیل به سؤال اضافه می‌شود. در حالت محلی فرمول به ascii-math و در حالت OpenAI به LaTeX تبدیل می‌شود؛ پشتیبانی از ورود یک نماد به معنی پشتیبانی حل‌گر محلی از آن نیست. کتابخانه هنگام باز کردن پنل بارگذاری می‌شود و فونت‌ها از خود اپ ارائه می‌شوند. استفاده از صفحه‌کلید درخواست مدل ندارد.

## CLI

```powershell
python cli.py 'x^2 - 5x + 6 = 0'
python cli.py 'مشتق چیست؟' --once
python cli.py 'x^2 - 4x + 4 = 0' --json --level beginner
npm run cli -- 'x^2 - 5x + 6 = 0' --once
```

`agent.py` آداپتور پایتون است که یک پردازش Node زنده را نگه می‌دارد. منطق Graph، Nodeها و State در `lib/agent.ts` قرار دارد و میان وب و هر دو CLI مشترک است. بنابراین این نسخه پیاده‌سازی مستقل هسته در Python نیست؛ اگر ارزیاب الزام داشته باشد Graph داخل خود agent.py باشد، این تفاوت باید اعلام شود. حالت تعاملی بعد از جواب، فهمیدم/نفهمیدم/ردکردن را دریافت می‌کند. CLI فرمول را به‌صورت LaTeX متنی نشان می‌دهد؛ نمودار تعاملی در وب است.

## معماری

```mermaid
flowchart TD
  E[entry] -->|image attached| I[read_image]
  E -->|text| A
  I -->|readable| A
  I -->|unreadable| Q
  A[analyze_question] -->|concept or problem| K[retrieve_context]
  K -->|concept| C[prepare_concept]
  K -->|problem| S[solve_problem]
  A -->|ambiguous| Q[clarify_question]
  C --> V[verify_result]
  S --> V
  V -->|failed, one repair| R[revise_answer]
  R --> V
  V -->|passed or inconclusive| P[plan_visual]
  P --> D[validate_visual]
  D --> T[teach]
  T --> W[wait for user]
  W --> U[assess_understanding]
  U -->|confused, attempts below 3| B[adapt_teaching]
  B --> V
  U -->|understood| E[encourage]
  E --> F[finalize]
```

State با StateSchema و reducer تجمیع trace تعریف شده است؛ Nodeها patch برمی‌گردانند. توقف برای کاربر به‌صورت وضعیت صریح در سرویس انجام می‌شود؛ این نسخه از interrupt/checkpointer پایدار LangGraph استفاده نمی‌کند. دو درخواست رفع ابهام، یک اصلاح، سه ارائه آموزشی، حداکثر ۱۰ فراخوانی موفق آداپتور و recursionLimit=40 سقف دارند. شمارنده فراخوانی، retry داخلی SDK را شامل نمی‌شود.

Runها در حافظه یک پردازش، با TTL یک ساعت، سقف ۲۰۰ نشست، مالکیت cookie تصادفی HttpOnly، قفل هر Run و eventId تکرارپذیر نگه‌داری می‌شوند. تاریخچه مرورگر فقط در حافظه صفحه است و با reload پاک می‌شود؛ State سرور با restart یا انقضای نشست از بین می‌رود. برای چند worker، استقرار ابری عمومی، ورود کاربران و ذخیره پایدار باید storage مشترک، احراز هویت و rate limit اضافه شود. این نسخه برای اجرای محلی است.

## ویژوال و توکن

[RAG تنظیم‌شده](./rag/README.md) از ۳۶ بخش معتبر OpenStax و ۵۱۸ قطعه استفاده می‌کند. بازیابی BM25 با واژه‌های فارسی/انگلیسی، حداکثر سه قطعه را به حل، آموزش، بررسی و بازآموزی می‌دهد. منابع با لینک، انتساب و مجوز کنار پاسخ نمایش داده می‌شوند. embedding پولی یا جست‌وجوی زنده سراسر وب فعال نیست. متن RAG در حالت OpenAI مصرف توکن ورودی دارد. ایندکس قابل بازسازی با `npm run rag:index` است.

نمودار چندجمله‌ای و بردار از ضرایب و مقدارهای ابزار ساخته می‌شوند. renderer فقط enum و داده محدود معتبر را دریافت می‌کند. تغییر slider، zoom و بازکردن نمودار درخواست مدل ندارد؛ این رفتار در مرورگر آزموده شده است. تولید VisualSpec در این MVP کاملاً محلی است و هیچ فراخوانی مدل مستقلی برای رسم ندارد. جابه‌جایی عمودی یک حالت آزمایشی است و جواب مسئله اصلی را عوض نمی‌کند.

هیچ کد مدل با eval اجرا نمی‌شود؛ نمودار از تصویر تولیدشده ساخته نمی‌شود و نقاط sampled به مدل ارسال نمی‌شوند. مصرف ورودی/خروجی OpenAI در State و جزئیات پاسخ ثبت می‌شود. درصد صرفه‌جویی و مصرف زنده هنوز اندازه‌گیری نشده‌اند.

## بررسی

```powershell
npm run typecheck
npm test
npm run test:e2e
npm run build
```

آزمون‌های هسته: ارقام فارسی، معادله دوطرفه، ریشه تکراری و نبود ریشه حقیقی، مشتق و بردار، رد عبارت خارج از parser، جواب خراب، مسیر مفهومی، سقف آموزش، clarification، مالکیت نشست، تکرار event و اصلاح محدود مدل. Playwright با Chrome نصب‌شده، جریان آموزش، بازخورد، نگه‌داری slider هنگام تایپ، صفر درخواست API برای نمودار و موبایل را بررسی می‌کند. تست‌ها را در حالت محلی اجرا کنید؛ حالت OpenAI می‌تواند هزینه داشته باشد.

فونت وزیرمتن با مجوز OFL در public/brand/OFL.txt همراه پروژه است. اجزای UI از CLI رسمی shadcn دریافت شده‌اند. منابع فنی: [LangGraph Graph API](https://docs.langchain.com/oss/javascript/langgraph/quickstart)، [shadcn Next.js](https://ui.shadcn.com/docs/installation/next)، [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). قواعد Next.js از راهنمای داخل بسته نصب‌شده خوانده شده‌اند.
